# SHOKH — Bangladesh Minimalist E-Commerce Store

**SHOKH** is a modern, minimalist online store built for Bangladesh selling **Watches, Glasses, T-Shirts, and Gift Products**, featuring nationwide Cash on Delivery (COD), Guest & Logged-in Checkout, Cloudinary + YouTube product media, and an integrated Admin Panel.

## Git Workflow

- `main` is protected — never commit directly to `main`.
- Branch off `main` / `develop` using `feat/*`, `fix/*`, `docs/*`, or `design/*` and merge via Pull Request.
